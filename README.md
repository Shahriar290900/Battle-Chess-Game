# Battle Chess: Emberhold vs the Rime Host

A cinematic 3D battle-chess game (three.js + GSAP + chess.js). Captures are staged fights: the attacker strikes, the defender shatters.
Play vs the computer (Stockfish) or pass-and-play on one device. Runs in desktop/mobile browsers and as an Android APK.

Work in progress. See `docs/DECISIONS.md`.

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # rules perft + replay tests
```
